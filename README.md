# Weather V0.4 · Unified Mobile System

V0.4 是天气产品的独立迭代版本，保留 V0.3，不覆盖原目录。当前版本主要修正移动端页面骨架、阅读规格、图标一致性和微动效可见性，并增加独立 SVG 组件库大画布。

## 当前交付

1. 产品入口：`/`
2. 组件库入口：`/design-system/`
3. 独立 SVG：`/weather-design-system-v0.4.svg`
4. 发布目标：`https://dodgey512-blake.github.io/`

## 页面结构

1. 带导航的页面统一为固定顶部栏、中间独立滚动区、固定底部导航。
2. 设置页统一为固定顶部栏、中间独立滚动区、固定底部 CTA。
3. 首页的天气内容整体滚动，但底部导航不参与滚动。
4. Running Pro 与风雨详情保留固定顶部栏，正文独立滚动。

## 设计规范

1. 正文最小字号 16px，辅助正文最小字号 14px，功能标签最小字号 12px。
2. 触控区域不小于 44px，间距以 8px 为基础。
3. 底部导航统一使用 Lucide 22px 线性图标、1.8px 描边和同一字体规格。
4. 荧光绿只用于选中、安全窗口和主操作，不用于替代图标内容。
5. 所有按钮包含按压反馈；选中、成功和导航切换包含 120–320ms 动效。
6. 晴天、降雨、雷暴包含可见的自然微动效，并兼容 `prefers-reduced-motion`。

## 本地运行
